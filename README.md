# I BE ZOMBIE

A stylized low-poly 3D urban horde-action prototype built with Three.js, TypeScript, and Vite. Control a zombie leader in a compact city district, recruit wandering walkers into an overwhelming swarm, navigate streets and service alleys, and breach a fortified human checkpoint.

## Commands

| Task | Command |
|---|---|
| Install | `npm install` |
| Dev server | `npm run dev` |
| Type-check + build | `npm run build` |
| Run tests | `npm test` |

See [`docs/1_design.md`](docs/1_design.md) and [`AGENTS.md`](AGENTS.md) for architecture and gameplay specifications.
